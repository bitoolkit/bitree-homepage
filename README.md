# bitree-homepage

[BITree 理枝](https://github.com/bitoolkit/BITree) 的官方网站源码：
面向北京理工大学的本地跨平台校园工具集。

- 线上地址：<https://bitoolkit.github.io/bitree-homepage/>
- 技术栈：Astro + TypeScript + 原生 CSS，静态输出，零运行时依赖
- 开发与部署说明见 [website/README.md](website/README.md)

```sh
cd website
npm install
npm run dev
```
